# LifeCare Clinic Website

A modern, professional, fully responsive doctor clinic website made with HTML, CSS, and JavaScript.

## Files

- `index.html`
- `style.css`
- `script.js`

## Features

- Responsive navbar with mobile hamburger menu
- Hero section with doctor image and trust cards
- About doctor section
- Services cards
- Appointment booking form
- WhatsApp appointment message generation
- Clinic timing table
- Gallery section
- Patient reviews
- FAQ accordion
- Contact form
- Google Map embed
- Dark mode toggle
- Floating WhatsApp button
- Back-to-top button
- Appointment success popup
- Doctor availability status
- Admin panel preview
- Print appointment slip option

## How to Run

1. Extract the ZIP file.
2. Open `index.html` in Chrome or any browser.
3. To edit clinic details, open files in VS Code.

## Important Customization

Open `script.js` and change:

```js
const WHATSAPP_NUMBER = "919876543210";
```

Open `index.html` and change:

- Clinic name
- Doctor name
- Phone number
- Address
- Google Map location
- Email
- Service details

## Created for

Doctor clinic, health center, small hospital, and local medical practice website projects.
